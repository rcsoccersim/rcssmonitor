rcssmonitor 全体の、まだしていない作業の一覧。計画書 (`docs/plan`) で対象外にしたものと、見送ったものを集めた。Web 版 (rcssmonitor-web) へ移す機能も §2 に書く。

## 使い方

- 1 項目 1 行。番号 (デスクトップ版は T1、T2、…、Web 版は W1、W2、…) は振り直さない。項目を消さず、状態を変える。
- 状態:
  - 未着手: いつかする。
  - 作業中: 計画書へのリンクを添える。
  - 完了: PR の番号を添える。
  - 見送り: しないと決めた。理由を添える (同じ検討を繰り返さないため)。
  - 未決: するかどうかを決めていない。決めることを添える。
- 規模の目安: 小 (1 日ほど)、中 (数日)、大 (1 週以上。計画書を作る)。
- 始めるときは `docs/plan` に計画書を作り、ここからリンクする。
- 計画書で対象外にしたもの、見送ったものは、ここにも足す (由来に計画書と節を書く)。
